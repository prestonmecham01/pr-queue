# Architecture Decision Records

Short records of decisions made in this project: what was decided, why, and what was rejected. Write one when a decision is made, not afterwards.

Files are named `NNNN-short-title.md` (for example `0001-nextjs-static-export.md`) so they sort in order.

## Template

Copy this into a new file. Keep it short. A few sentences per section is enough.

```markdown
# NNNN. Title

**Date:** YYYY-MM-DD
**Status:** Proposed | Accepted | Superseded by NNNN

## Headline
One sentence: the decision and the main reason.

## Decision
What was decided.

## Why
The reasons, and the constraints that shaped it.

## Alternatives rejected
- Option: why it was rejected.

## Evidence
Numbers, measurements, test results, links to docs. Write "none yet" if there is none.

## What I would change
Known weaknesses, and what would make me revisit this.
```

If AI feedback influenced the decision, add a line under Why: "Informed by a local, manual review (persona name, date)." Decisions and numbers must be the author's own and verified.
